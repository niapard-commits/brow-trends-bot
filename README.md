# brow-trends-bot

Приватний збирач для Brow Trends Digest: щотижня шукає **публічні** дописи Threads за ключовими словами
(`keywords.json`, українською/словацькою/англійською) через офіційний Threads API (`keyword_search`).

- Нічого не публікує, не відповідає, не підписується.
- Зберігає лише текст, ім'я користувача, посилання, час, тип медіа (`data/raw/YYYY-MM-DD.json`).
- Сирі файли старші за 90 днів видаляються автоматично (відповідає політиці конфіденційності).
- `data/digest-input.md` це короткі уривки з посиланнями для тижневого дайджесту.
- Токен: секрет `THREADS_TOKEN` (початковий), далі сам оновлюється і лежить у `data/token.json`. Репозиторій має лишатись **Private**.
- Не пов'язаний із ботом каналу «Лут і Серія».

Запуск: Actions → collect → Run workflow. Тести: `python -m pytest`.
